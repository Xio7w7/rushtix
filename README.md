# RushTix

Sitio de venta de boletos para eventos de último minuto. Proyecto de Programación Orientada al Usuario (POU), UCA.

Lema: "Precio final desde el primer vistazo".

Esta es la primera parte del sitio, hecha a partir del diseño de Figma.

## Páginas

- `index.html`: inicio, con los eventos, el buscador y los filtros.
- `login.html`: iniciar sesión.

Los estilos están en la carpeta `css/` (`inicio.css` y `login.css`).

## Para abrirlo

WiP

## Hecho con

HTML y CSS, sin frameworks. Modo oscuro.
